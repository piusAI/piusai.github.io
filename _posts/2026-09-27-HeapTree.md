"Pointer없이 배열 인덱스 계산만으로 트리를 표현"
완전 이진트리 (BT)구조라면 포인터없이 배열에 순서대로 넣고, index 계산만으로 부모/자식 관계 알아낼 수있다!

일반적인 Tree : 노드마다 



### Heap vs Stack


| 특징    | Heap                        | Stack        |
| ----- | --------------------------- | ------------ |
| 용도    | Priority(우선순위) 큐, heap Sort | 함수 호출, 지역 변수 |
| 구조    | 완전 이진 트리                    | LIFO         |
| 메모리   | 동적 할당 영역                    | 자동 할당 영역     |
| 접근    | 루트 노드만 직접 접근                | Top만 접근 가능   |
| 시간복잡도 | 삽입/삭제 : O(log n)            | 삽입/삭제 : O(1) |

#### HeapTree 조건

**1법칙**
- 자식 노드 < 부모노드 (maxheap 기준)
- 마지막 깊이 빼고는 모두 차있다 (완전 BT)
- 마지막 레벨에서의 노드는 왼쪽부터 채우기
**2법칙**
- 노드 갯수알면 트리 구조 확정 가능
- $2^h-1$가 아니더라도 무조건 트리 구조 확정 가능!

BST는 자식 왼쪽 Subtree< 부모 < 오른쪽 subtree

#### 배열을 활용한 HeapTree

<table width="90%" style="table-layout: fixed; border-collapse: collapse; border: none;"> <tr style="border: none;"> <td width="100%" style="text-align: center; border: none; padding: 15px;"> <img src="/assets/postimg/Tree/HeapTree/HeapTreeArray.png" alt="VS003" style="width: 100%; max-width: 100%; height: auto;"> <br><strong>HeapTree in Array</strong> </td>  </tr> </table>
- i번 노드 자식 왼쪽 : $(2*i) +1$
- i번 노드 자식 오른쪽 : $(2*i)+2$
- i번째 부모 : $floor(i-1/2)$

CBT Algorithm2에서와 같이 인덱싱으로 표현 가능!


#### 새로운 값 추가
- 자식-부모 간의 구조 비교해서 Swap!

##### 최댓값 꺼내기
1. 가장 Root node를 꺼낸다
2. 가장 마지막 data -> Root로 옮긴다
3. 다시 Root와 자식 노드간의 비교 후 Swap!

위 그래프를 cpp로 구현해보자

```cpp
#include <iostream>
using namespace std;
#include <queue> //vector가 안에 차피 들어가있음
void graph01()
{
    struct vtx {
        vector<vtx*> edges;
    };

    vector<vtx> weightGraph(4);

    weightGraph[0].edges.push_back(&weightGraph[1]);
    weightGraph[0].edges.push_back(&weightGraph[3]);

    weightGraph[1].edges.push_back(&weightGraph[0]);
    weightGraph[1].edges.push_back(&weightGraph[0]);
    weightGraph[1].edges.push_back(&weightGraph[0]);

    weightGraph[2].edges.push_back(&weightGraph[1]);

    weightGraph[3].edges.push_back(&weightGraph[0]);

}

int main()
{
    graph01();
}
```

| |`vector<vector<int>>`|`vector<Mystruct>`|
|---|---|---|
|접근|`adjacent[i][j]`|`ad[i].vt[j]`|
|추가|`adjacent[i].push_back(3)`|`ad[i].vt.push_back(3)`|
|크기|`adjacent[i].size()`|`ad[i].vt.size()`|
|선언|한 줄|struct 정의 필요|

메모리 구조는 같다 사용법에 차이가 있을 뿐이다.

### 인접 리스트 

인접리스트 : O(V+E)
행렬 : O(V<sup>2</sup>)






|       | Adjacent Matrix                   | Adjacent List          |
| ----- | --------------------------------- | ---------------------- |
| 초기화   | `Adjacent={ {1,3},{1} };`         | `Adjacent[0]={1,2,4};` |
| 넣는 방법 | `Adjacent[from][to] = true;`      | `Adajcent.push(3);`    |
| 읽는 방법 | `Adjacent[from][to]`              | `Adjacent[from][to]`   |
| 특징    | 행렬을 이용한 그래프 표현, 메모리 소모 심하지만 빠른 접근 | Data 품어서 필요없는 정보 없다    |
| 비유    | Vector 동적 배열                      | 연결 리스트                 |
| ex    | 카톡 친구                             | 지하철 노선도                |
| Big-O | O(V<sup>2</sup>)                  | O(V+E)                 |
|       | 연결 되었는지를 많이 찾을때(빠른접근)             | 이웃을 많이 순회해야할때          |

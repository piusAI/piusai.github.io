### 1. LEB 이해와 구현
:이분할, 이웃 연쇄분할, Edge Hash Key 3가지만 활용
기존 LEB에서 AIZ 추가됨(`refine()`)

- 지형은 한 변이 `L`인 정 사각형, 정수 격자 `0..G`(`G = 2^K`)위에 놓인다.
- 삼각형은 정수 꼭짓점 3개 `V[0], V[1], V[2]`이다. `V[1]`이 직각 꼭짓점이고 `V[0]-V[2]`가 빗변
- 분할은 하나 뿐, 빗변 중점 M을 직각 꼭짓점과 이어 둘로 가른다.
- 나눈 결과도 이등변 직각 삼각형으로, 규칙 이어서 적용가능
- 한 곳만 쪼개면 이웃과 틈이 생기니, 빗변 건너편 이웃도 함께 쪼갠다 : conforming

- `heapPop`은 Priority 수치가 작은 것 먼저 꺼낸다.

**핵심**:  
1. 정확한 2D 점-삼각형 거리 계산
2. 균일한 기본 grid 사전 분할 - BFS를 통해 기본 삼각형들을 MinimumDepth 수준까지 균일하게 분할
   ->이로 corase triangle을 가로지르는 길고 뾰족한 형태의 분할을 완전히 제거한다.
3. Min-Heap 우선순위 큐 기반 세분화 : deficit(오차)가 가장 크고 상호 작용 지점과의 거리가 가장 가까운 삼각형부터 우선적 세분화
   DFS tree 순서에 따른 편향을 제거하고, 세부 정보가 Player로부터 대칭적으로 바깥쪽을 향ㅎ ㅐ퍼져나가도록
4. 일관된 이등분(Conforming BisectionGuarantee): 인접 삼각형을 다이아몬드 형태로 함꼐 이등분해 T-junction Crack 발생치 않도록함.
5. Hash Map을 사용하지 않는 고속 버퍼 생성 - vtx, normal UV, index data를 O(N)시간 복잡도로 직접 선형 배열에 구성


## 1. LEB 이해 (A 영역)

### 1.1 한 장 요약

- 지형은 한 변이 `L`인 정사각형이고, 정수 격자 `0..G` (`G = 2^K`) 위에 놓입니다.
- 삼각형은 **정수 꼭짓점 3개** `V[0], V[1], V[2]`입니다. `V[1]`이 직각 꼭짓점이고 `V[0]–V[2]`가 빗변입니다.
- 분할은 하나뿐입니다. **빗변의 중점 M을 직각 꼭짓점과 이어 둘로 가른다.**
- 가른 결과도 이등변 직각삼각형이므로 같은 규칙을 계속 적용할 수 있습니다.
- 한 곳만 쪼개면 이웃과 틈이 생기므로, **빗변 건너편 이웃도 함께 쪼갭니다.** (conforming)

```cpp
// 구조체 (FIZLEB_v08_1_1.h)
struct FIZLebTriangle { uint32 NodeID; FIntPoint V[3]; int32 Depth; bool bAlive; };
//  V[0]──빗변──V[2],  V[1] = 직각 꼭짓점,  Depth = 분할 횟수,  bAlive = 현재 리프인가
```

### 1.2 분할 규칙 (코드 `SplitOne`)

```
M = (V0 + V2) / 2                  // 정수 나눗셈 (아래 1.5 참고)
자식0 = (V1, M, V0)
자식1 = (V2, M, V1)
```

아래는 1.3의 base0 = V0(0,0), V1(2,0), V2(2,2) 를 쪼갠 모습입니다.

```
                  V2 (2,2)
                 ╱│
               ╱  │
        M(1,1)╱ 자식1: (V2, M, V1)
            ╱  ╲  │
          ╱ 자식0 ╲│
      V0 ──────────V1 (2,0)          자식0: (V1, M, V0)
   (0,0)                              M 과 V1 을 이은 선이 새 경계
```

두 자식 모두 직각 꼭짓점이 M이고, 자식0의 새 빗변은 V1–V0, 자식1의 새 빗변은 V2–V1입니다.

핵심 성질 두 가지만 기억하면 됩니다.

1. 자식의 **새 빗변은 부모의 직각변**이고, 직각 꼭짓점은 **M**입니다.
2. 분할할 때마다 삼각형 면적이 정확히 절반이 되고, 모양은 **항상 이등변 직각삼각형(서로 닮음)** 입니다. 가늘고 긴 삼각형이 생기지 않습니다.

**ComputeDistanceToTriangle2D** : 
- Query 지점과 2D 삼각형 사이의 정확한 Euclidean 거리
- 점이 삼각형 내부 / 경계위에 있으면 0.0f 반환
``` cpp
	
	static FORCEINLINE float ComputeDistanceToTriangle2D(
		const FVector2D& Point,
		const FVector2D& A,
		const FVector2D& B,
		const FVector2D& C)
	{
		// 1. 2D Crossproduct 활용해서 삼각형이 내부에 있는지 판별
		const float Cross0 = (B.X - A.X) * (Point.Y - A.Y) - (B.Y - A.Y) * (Point.X - A.X); //A, B, Point 
		const float Cross1 = (C.X - B.X) * (Point.Y - B.Y) - (C.Y - B.Y) * (Point.X - B.X); //B, C, Point
		const float Cross2 = (A.X - C.X) * (Point.Y - C.Y) - (A.Y - C.Y) * (Point.X - C.X); //C, A, Point

		const bool bHasNeg = (Cross0 < -1e-4f) || (Cross1 < -1e-4f) || (Cross2 < -1e-4f);
		const bool bHasPos = (Cross0 > 1e-4f) || (Cross1 > 1e-4f) || (Cross2 > 1e-4f);

		// 내부인지 외부인지 확인 가능
		if (!(bHasNeg && bHasPos))
		{
			return 0.0f; // 내부라면 0
		}
		
	// 2. 점이 밖이라면, 세 변으로부터 거리제곱을 구하기
	
		auto DistSqToSegment = [](const FVector2D& P, const FVector2D& S0, const FVector2D& S1) -> float
		{
			const FVector2D D = S1 - S0;
			const float LenSq = D.SizeSquared();
			if (LenSq <= 1e-6f)
			{
				return FVector2D::DistSquared(P, S0);
			}
			const float T = FMath::Clamp(((P.X - S0.X) * D.X + (P.Y - S0.Y) * D.Y) / LenSq, 0.0f, 1.0f);
			const FVector2D Proj = S0 + D * T;
			return FVector2D::DistSquared(P, Proj);
		};

		const float D0 = DistSqToSegment(Point, A, B);
		const float D1 = DistSqToSegment(Point, B, C);
		const float D2 = DistSqToSegment(Point, C, A);

		return FMath::Sqrt(FMath::Min3(D0, D1, D2));
	}
```
	
###### 1. 2D Crossproduct 활용해서 삼각형이 내부에 있는지 판별
1. (A, B, Point), (B, C, Point), (C, A, Point)의 외적
2. 결과가 양수 : 세점이 CCW(반시계) - 점이 A->B 진행방향 왼쪽
3. 결과가 음수 : 세점이 CW(시계방향)
4. bHasNeg && bHasPos로 삼각형 내부에 있다면 부호가 한종류여서 
  True라 0을 반환

**ComputeContinuousTargetDepth**:
연속되는 Target depth를 smooth step으로 구한다
```cpp
	static FORCEINLINE float ComputeContinuousTargetDepth(
		float Dist,
		const FIZRefineParams& Params,
		int32 DepthLimit,
		float RadialFalloffSharpness = 1.0f)
	{
		const float MinDist = FMath::Max(10.0f, Params.MinDistance);
		const float MaxDist = FMath::Max(MinDist + 10.0f, Params.RefineDistance);

		if (Dist >= MaxDist)
		{
			return 0.0f;
		}
		if (Dist <= MinDist)
		{
			return static_cast<float>(DepthLimit);
		}

		float Alpha = 1.0f - (Dist - MinDist) / (MaxDist - MinDist);
		if (RadialFalloffSharpness != 1.0f && Alpha > 0.0f)
		{
			Alpha = FMath::Pow(Alpha, RadialFalloffSharpness);
		}
		const float SmoothAlpha = Alpha * Alpha * (3.0f - 2.0f * Alpha);

		return FMath::Clamp(SmoothAlpha * static_cast<float>(DepthLimit), 0.0f, static_cast<float>(DepthLimit));
	}
```
연속되는 target depth를 Parameter로부터 구한다
-  Alpha : 거리를 0~1로 정규화한 값
- Sharpness : Alpha의 곡선 모양을 바꾼다, 1보다 크면 Alpha가 빨리 줄어서 가까운 곳에만 Detail 몰리고, 1보다 작으면 멀리까지 detail이 퍼진다.
- SmoothStep : `Alpha²(3 - 2·Alpha)` : 0과 1부근에서 변화가 완만, 가운데서 가파른 S자 곡선 
- Clamp : SmoothStep 결과가 0~SmoothAlpha로 추가 방어
- 결과 = `Smoothstep*DepthLimit`

**SplitConforming**:
- TriIndex에 해당하는 삼각형 세분화 하고, 엄격하게 일치하는 T-Junctino이나 틈새 없는 Geometry 구조를 유지하기 위해 인접한 Diamond형태의 삼각형들도 재귀적으로 세분화!
```cpp
	void SplitConforming(int32 TriIndex, TArray<int32>& OutNewLeaves)
	{
		int32 SafetyCounter = 0;
		while (SafetyCounter++ < 1000) //while 최대 1000번
		{
			if (!Triangles.IsValidIndex(TriIndex) || !Triangles[TriIndex].bAlive)
			{
				return;
			} //triindex 죽었거나 유효치 않으면 return

			const FIZLebTriangle_v08_1_1 T = Triangles[TriIndex];
			if (T.Depth >= MaxDepth())
			{
				return;
			}
	// 빗변 키(HypKey)로 이웃 찾는다
			const uint64 HypKey = MakeEdgeKey(T.V[0], T.V[2]);
			const int32 NeighborIndex = GetOtherEdgeUser(HypKey, TriIndex);
	//이웃이 없다면
			if (NeighborIndex == INDEX_NONE)
			{
				SplitOne(TriIndex, OutNewLeaves); //메시 경게, SplitOne(나)
				return;
			}

			const FIZLebTriangle_v08_1_1& Neighbor = Triangles[NeighborIndex];
			const uint64 NeighborHypKey = MakeEdgeKey(Neighbor.V[0], Neighbor.V[2]);

			if (NeighborHypKey == HypKey) //이웃의 빗변 == 내 빗변
			{
				SplitOne(TriIndex, OutNewLeaves); //서로공유하는 짝 SplitOne(나)
				SplitOne(NeighborIndex, OutNewLeaves); //SplitOne(이웃)
				return;
			}
			//이웃 빗변 != 내 빗변 : 나는 빗변, 이웃은 짧은 변
			SplitConforming(NeighborIndex, OutNewLeaves); //이웃 재귀 호출
		}
	}
	
```
- `NeighborIndex` : GetOtherEdgeUser로 다른 EdgeUser 찾는다.
- `MakeEdgeKey` : triangle[0], triangle[2]를 64비트로 채워줌 (작은 값을 앞에두는 정렬)
- `SplitOne` : `TriIndex`삼각형을 죽이고( `bAlive=false`), 빗변 중점`M`을 기준으로 자식 삼각형 2개를 만들어 `Triangles`에 추가한뒤, 그 자식들의 인덱스를 `OutNewLeaves`에 덧붙힌다.

- 분기
  A. 이웃 없음 : 빗변 반대편에 삼각형이 없으니, 쪼개도 없으니 나만 SplitOne
  B. 빗변 공유 : 내 빗변이 이웃도 빗변이면 둘다 Diamond SplitOne
  C. 빗변이 다름 : 내빗변이 이웃에게는 짧은 변 - while이기에, 이웃 먼저 정리 이후, 나는 다음 반복에서 다시 시도

**Refine**:  
Priority queue를 활용해서 Grid 전체에 걸쳐 Fulled 적응형 Radial(방사형) 세분화 실행
```cpp
void Refine(
	const FIZInteractionData& Interaction,
	const FTransform& ComponentTransform,
	const FIZRefineParams& Params,
	float DetailWeight = 1.0f,
	const TArray<FIZTimedDetailSample>* TimedDetailSamples = nullptr,
	float CurrentTime = 0.0f,
	float DetailHoldDuration = 0.0f,
	float DetailDecayRate = 1.0f,
	float MinDetailWeight = 0.01f,
	bool bEnableHysteresis = true,
	bool bUseExactTriangleDistance = true,
	float RadialFalloffSharpness = 1.0f,
	float PredictiveLookAhead = 0.08f)
{
//0. 준비
		Reset();

		const float CellSize = Params.TerrainSize / static_cast<float>(G);
		const int32 EffectiveMaxDepth = FMath::Min(Params.MaxSubdivLevel * 2 - 1, MaxDepth());

		int32 BudgetSafeMinLevel = FMath::Clamp(Params.MinSubdivLevel, 1, Params.MaxSubdivLevel);
		while (BudgetSafeMinLevel > 1 &&
			(2ll * (1ll << (2 * BudgetSafeMinLevel))) > FMath::Max(2, Params.MaxTriangles))
		{
			--BudgetSafeMinLevel;
		}
		const int32 MinimumDepth = FMath::Min(2 * BudgetSafeMinLevel - 1, EffectiveMaxDepth);
		const float ClampedDetailWeight = FMath::Clamp(DetailWeight, 0.0f, 1.0f);

		TArray<int32> NewLeaves;
		NewLeaves.Reserve(16);

		// 1. Uniform Base Grid Pass:
		// Pre-split the entire mesh in BFS order to MinimumDepth so the base grid is
		// 100% symmetric and uniform. Eliminates long needle splits across huge coarse triangles.
		if (MinimumDepth > 0)
		{
			TArray<int32> BaseQueue;
			BaseQueue.Reserve(1024);
			BaseQueue.Add(0);
			BaseQueue.Add(1);
			int32 HeadIdx = 0;
			while (HeadIdx < BaseQueue.Num())
			{
				const int32 TriIdx = BaseQueue[HeadIdx++];
				if (!Triangles.IsValidIndex(TriIdx) || !Triangles[TriIdx].bAlive)
				{
					continue;
				}
				if (Triangles[TriIdx].Depth < MinimumDepth && LeafCount < Params.MaxTriangles)
				{
					NewLeaves.Reset();
					SplitConforming(TriIdx, NewLeaves);
					BaseQueue.Append(NewLeaves);
				}
			}
		}

		// 2. Prepare component-local interaction coordinates
		const FVector PredictedWorldSource = Interaction.Location + Interaction.Velocity * PredictiveLookAhead;
		const FVector LocalPlayerPos = ComponentTransform.InverseTransformPosition(PredictedWorldSource);
		const FVector2D LocalPlayerPos2D(LocalPlayerPos.X, LocalPlayerPos.Y);

		// Lambda to evaluate distance, desired depth, and priority for any triangle
		auto EvaluateTriangleMetrics = [&](const FIZLebTriangle_v08_1_1& T, float& OutDist, int32& OutDesiredDepth)
		{
			const FVector2D L0((T.V[0].X - G * 0.5f) * CellSize, (T.V[0].Y - G * 0.5f) * CellSize);
			const FVector2D L1((T.V[1].X - G * 0.5f) * CellSize, (T.V[1].Y - G * 0.5f) * CellSize);
			const FVector2D L2((T.V[2].X - G * 0.5f) * CellSize, (T.V[2].Y - G * 0.5f) * CellSize);

			float Dist = 0.0f;
			if (bUseExactTriangleDistance)
			{
				Dist = ComputeDistanceToTriangle2D(LocalPlayerPos2D, L0, L1, L2);
			}
			else
			{
				const float MinX = FMath::Min3(L0.X, L1.X, L2.X);
				const float MaxX = FMath::Max3(L0.X, L1.X, L2.X);
				const float MinY = FMath::Min3(L0.Y, L1.Y, L2.Y);
				const float MaxY = FMath::Max3(L0.Y, L1.Y, L2.Y);
				const float ClampedX = FMath::Clamp(LocalPlayerPos2D.X, MinX, MaxX);
				const float ClampedY = FMath::Clamp(LocalPlayerPos2D.Y, MinY, MaxY);
				Dist = FVector2D::Distance(LocalPlayerPos2D, FVector2D(ClampedX, ClampedY));
			}
			OutDist = Dist;

			float MaxScaledDeficit = 0.0f;
			if (ClampedDetailWeight > 0.0f)
			{
				const float ContTarget = ComputeContinuousTargetDepth(Dist, Params, EffectiveMaxDepth, RadialFalloffSharpness);
				MaxScaledDeficit = FMath::Max(MaxScaledDeficit, FMath::Max(0.0f, ContTarget - static_cast<float>(MinimumDepth)) * ClampedDetailWeight);
			}

			if (TimedDetailSamples)
			{
				for (const FIZTimedDetailSample& Sample : *TimedDetailSamples)
				{
					const float SampleWeight = IZTemporalTessellationCompensation::ComputeWeight(
						CurrentTime - Sample.LastTouchTime,
						DetailHoldDuration,
						DetailDecayRate,
						MinDetailWeight);
					if (SampleWeight <= 0.0f)
					{
						continue;
					}

					const FVector LocalSamplePos = ComponentTransform.InverseTransformPosition(Sample.Interaction.Location);
					const FVector2D LocalSample2D(LocalSamplePos.X, LocalSamplePos.Y);
					const float SampleDist = bUseExactTriangleDistance
						? ComputeDistanceToTriangle2D(LocalSample2D, L0, L1, L2)
						: FVector2D::Distance(LocalSample2D, FVector2D(
							FMath::Clamp(LocalSample2D.X, FMath::Min3(L0.X, L1.X, L2.X), FMath::Max3(L0.X, L1.X, L2.X)),
							FMath::Clamp(LocalSample2D.Y, FMath::Min3(L0.Y, L1.Y, L2.Y), FMath::Max3(L0.Y, L1.Y, L2.Y))));

					const float SampleTarget = ComputeContinuousTargetDepth(SampleDist, Params, EffectiveMaxDepth, RadialFalloffSharpness);
					MaxScaledDeficit = FMath::Max(MaxScaledDeficit, FMath::Max(0.0f, SampleTarget - static_cast<float>(MinimumDepth)) * SampleWeight);
				}
			}

			OutDesiredDepth = FMath::Clamp(MinimumDepth + FMath::RoundToInt(MaxScaledDeficit), MinimumDepth, EffectiveMaxDepth);
		};

		// 3. Populate Priority Queue with active leaf candidates
		TArray<FIZRefineCandidate_v08_1_1> AdaptiveQueue;
		AdaptiveQueue.Reserve(Triangles.Num() * 2);

		for (int32 i = 0; i < Triangles.Num(); ++i)
		{
			if (!Triangles[i].bAlive)
			{
				continue;
			}
			const FIZLebTriangle_v08_1_1& T = Triangles[i];
			if (T.Depth >= EffectiveMaxDepth)
			{
				continue;
			}

			float Dist = 0.0f;
			int32 DesiredDepth = MinimumDepth;
			EvaluateTriangleMetrics(T, Dist, DesiredDepth);

			const int32 Deficit = DesiredDepth - T.Depth;
			if (Deficit > 0)
			{
				// Higher deficit and closer distance get highest priority
				const float Priority = (static_cast<float>(Deficit) * 100000.0f) - Dist;
				AdaptiveQueue.HeapPush(FIZRefineCandidate_v08_1_1{i, Priority});
			}
		}

		// 4. Adaptive Refinement Loop with Max-Heap Priority Queue
		while (AdaptiveQueue.Num() > 0)
		{
			if (LeafCount >= Params.MaxTriangles)
			{
				break;
			}

			FIZRefineCandidate_v08_1_1 Candidate;
			AdaptiveQueue.HeapPop(Candidate, EAllowShrinking::No);

			const int32 TriIndex = Candidate.TriIndex;
			if (!Triangles.IsValidIndex(TriIndex) || !Triangles[TriIndex].bAlive)
			{
				continue;
			}

			const FIZLebTriangle_v08_1_1& T = Triangles[TriIndex];
			if (T.Depth >= EffectiveMaxDepth)
			{
				continue;
			}

			float Dist = 0.0f;
			int32 DesiredDepth = MinimumDepth;
			EvaluateTriangleMetrics(T, Dist, DesiredDepth);

			if (T.Depth < DesiredDepth)
			{
				NewLeaves.Reset();
				SplitConforming(TriIndex, NewLeaves);

				for (int32 NewLeafIdx : NewLeaves)
				{
					if (!Triangles.IsValidIndex(NewLeafIdx) || !Triangles[NewLeafIdx].bAlive)
					{
						continue;
					}
					const FIZLebTriangle_v08_1_1& ChildT = Triangles[NewLeafIdx];
					if (ChildT.Depth >= EffectiveMaxDepth)
					{
						continue;
					}

					float ChildDist = 0.0f;
					int32 ChildDesiredDepth = MinimumDepth;
					EvaluateTriangleMetrics(ChildT, ChildDist, ChildDesiredDepth);

					const int32 ChildDeficit = ChildDesiredDepth - ChildT.Depth;
					if (ChildDeficit > 0)
					{
						const float ChildPriority = (static_cast<float>(ChildDeficit) * 100000.0f) - ChildDist;
						AdaptiveQueue.HeapPush(FIZRefineCandidate_v08_1_1(NewLeafIdx, ChildPriority));
					}
				}
			}
		}
	}
```


① Reset 준비 :

```cpp
while (BudgetSafeMinLevel > 1 &&                                      // 레벨이 1보다 크고
    (2ll * (1ll << (2 * BudgetSafeMinLevel)))                         // 2 × 4^Level 이
        > FMath::Max(2, Params.MaxTriangles))                         // max(2, MaxTriangles)보다 크면
{
    --BudgetSafeMinLevel;                                             // 레벨을 1 내린다
}
```
- `2 x 4^Level` : 삼각형 수의 넉넉한 추정치, 실제 개수 는 `4^Level`, 코드는 그 2배로 잡음
- Maxtriangles로 최소 루트 삼각형 2개로 보존하는 방어코드
 Reset :  
`Triangles`, `Edges`, `LeafCount`를 비우고 Root 삼각형 2개(인덱스 0,1)만 만든다. `Refine`은 호출 될때마다 시행하니 **매번 처음부터 다시 만드는 구조**


② Uniform Base GridPass(균일 BFS 선 분할) :
- 전체 Mesh를 거리에 상관없이 인덱스 0,1에서 시작해 `MinimumDepth`까지 `SplitConforming` - (`BaseQueue.Add(0)`, `BaseQueue.Add(1)` 두 root 삼각형에서 시작)
- BFS(Queue를 활용)에 따라 Minimum Depth 수준까지  미리 분할하여, 기본 Grid가 100% 대칭적이고, 균일하게 만든다. 
- 효과 : 거대한 Coarse 삼각형을 가로지르는 가늘고 긴 needle분할 없애고, base Grid를 대칭으로 만듦
 - 쪼갤때마다 `LeafCount < MaxTriangles`를 비교


③ 플레이어 위치 준비 + `EvaluateTriangleMetrics`

- 예측은 Player에만 적용, Sample에는 적용x
- `EvaluateTriangleMetrics(삼각형)` : 
  -> `Dist`, `DesiredDepth`를 Outparameter로 뱉음
  1. 꼭짓점을 Local 좌표로 변환
  2. `ComputeDistanceToTriangle2D` 로 플레이어와 삼각형 사이의 2D 거리를 구해서 `Dist`
  3. `ComputeContinuousTargetDepth`로 Target Depth 구한다
  4. **MaxScaledDeficit** : 기본 격자위로 더 필요한 양
    -> `(목표 - MinimumDepth) x DetailWeight`
  5. `TimedDetailSamples`의 각 샘플도 같은 방식으로 한다. 시간 가중치 `ComputeWeight`를 구하고, 0이하면 건너뛰고, 샘플 위치로 거리, 목표를 구해서 `(목표 -MinimumDepth) x SampleWieght` 를 만든다
  6. 위 값중 최댓값 Max를 `MaxScaledDeficit`으로 잡음
  7. `DesiredDepth = clamp(minimumDepth + RoundToInt(MaxScaledDeficit), MinimumDepth, EffectiveMaxDepth)`
- `ComputeWeight` : footprint 샘플마다 같은 방식으로 거리 구하고 시간 가중치 곱함

④ Queue 초기화:  
`AdaptiveQueue`배열에다가 적용
- 살아있는 모든 Leaf중, `Depth < EffectiveMaxDepth`인 것만 평가
- `Deficit:` 삼각형이 목표까지 남은 분할 횟수
  -> `DesiredDepth - T.Depth` 
- `Deficit>0`이면 `Pirority = Deficit x 100000 -Dist`로 Push
- `HeapPush`는 `TLess: Operater<`로 작은것이 우선순위가 높음 push

⑤ Pop -> 분할 -> 재평가
"가장 급한 삼각형 하나 꺼내서 쪼개고, 새로 생긴 자식중 더 쪼개야 할걸 다시 Queue에 넣는일 반복"

1. `LeafCount >= MaxTriangles`면 중단
2. `AdaptiveQueue`.Heappop으로 하나 꺼낸다, `Alive`확인,
   죽었으면 버리기(Lazy Deletion) - (검증 )
3. `EvaluateTriangleMetrics`를 다시 돌리고(재평가, 방어용 중복)
4. `T.Depth < DesiredDepth`이면 `SplitConforming`한다 (분할조건)
5. `NewLeaves`의 각 새 리프마다
   - 죽었거나, `EffectiveMaxDepth`로 도달했으면 건너뜀
   - 평가해서 `deficit>0`이면 Heap Push

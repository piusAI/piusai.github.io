# 깊이 불연속 보정을 적용한 뉴턴 기반 화면 공간 굴절 — 수식 정리

## 0. 전체 흐름 한눈에 보기

```
[3.2] 좌표 변환 (1) → 굴절 광선 (2)
        ↓
[3.3] 현재 후보 u_i 에서 배경 위치 Q_i, 법선 n_i 복원
        → 접평면 ∩ 굴절 광선 → t_i, u*  (3)
        ↓
[3.4] 깊이 불연속 검사 (4)(5) → 감쇠 계수 λ_i (6) → 보정 후보 (7)
        ↓
[3.5] 수렴 판정 (8)(9)  ※ 보정 "전" 후보 기준
        ↓
[3.6] 최종 색 합성 (10)
```

## 2. 좌표계 변환과 굴절 광선 (3.2절)

### 식 (1) — ViewRect UV → 텍스처 UV

$$ u_{buf} = (o + s_{vp} \odot u) \oslash B \tag{1} $$

- $u$에 $s$를 성분별로 곱해 **ViewRect 안의 픽셀 위치**를 구하고, $o$를 더해 **텍스처 전체 기준 픽셀 위치**로 옮긴 뒤, $B$로 나눠 **정규화**한다.
- $\odot$ = 성분별 곱, $\oslash$ = 성분별 나눗셈.
- 필요한 이유: 뷰포트(ViewRect)와 장면 텍스처의 할당 크기가 다를 수 있기 때문이다.
- 사용 위치: 광선 투영·후보 갱신은 ViewRect 좌표로 하고, **텍스처 조회 직전**에만 이 식을 적용한다. 이웃 픽셀 조회(식 4~5)에도 적용한다.

| 기호        | 의미                        | 단위/비고      | Code                        |
| --------- | ------------------------- | ---------- | --------------------------- |
| $u$       | ViewRect 기준 정규화 UV        | 무차원, [0,1] | `ViewUV`                    |
| $u_{buf}$ | 텍스처 전체 기준 정규화 UV          | 텍스처 조회용    |                             |
| $o$       | ViewRect의 픽셀 원점           | 픽셀         | `ViewRectMinAndSize.xy`     |
| $s_{vp}$  | ViewRect의 가로·세로 픽셀 수      | 픽셀         | `ViewRectMinAndSize.zw`     |
| $B$       | 텍스처의 할당 크기                | 픽셀         |                             |
| $1/B$     | 샘플링할 Texture의 가로 세로크기의 역수 |            | `ViewportSizeAndInvSize.zw` |

```cpp
//hlsl .ush
float2 RefractionBufferUV(float2 ViewUV)
{
return (ViewRectMinAndSize.xy + ViewUV * ViewRectMinAndSize.zw) * ViewportSizeAndInvSize.zw;
}


// RefractMethodRenderer.cpp
const FVector4f ViewportSizeAndInvSize(
	(float)Resolution.X, (float)Resolution.Y,
	1.f / (float) Resolution.X, 1.f / (float) Resolution.Y
	);
```

### 식 (2) — 굴절 광선과 화면 투영

$$ R(t) = s + t,d, \qquad u(t) = \pi\big(R(t)\big) \tag{2} $$

- 광선은 시작점 $S$에서 방향 $d$로 뻗는 직선이다.
- $u(t)$는 광선 위의 점을 화면 UV로 투영한 값이다.
- 반복 중에는 $S$와 $d$를 **고정**하고, 배경 깊이를 읽을 후보 UV만 갱신한다.

**식 (2)에 딸린 본문 정의 (번호 없음)**

|항목|내용|
|---|---|
|입사 방향|카메라를 원점으로 두고 $S$를 정규화한 벡터|
|대상 표면 법선|상·하·좌·우 위치를 복원 → 각 축에서 중심과의 깊이 차가 **작은 쪽** 선택 → 두 차분벡터의 **외적 정규화**. 외적이 퇴화하면 대체 법선 사용|
|법선 방향|입사 방향의 반대쪽으로 맞춤|
|굴절 방향 $d$|공기→매질 굴절률 비 (IOR 1.05 → 비율 $1/1.05$)를 HLSL `refract`에 전달, 반환 벡터를 정규화. 퇴화 시 **반사 방향** 사용|
|초기 후보|$S$에서 **100 cm** 진행한 점을 투영. 화면 밖이면 대상 픽셀의 화면 좌표 사용|
|선형 깊이|장치 깊이를 역투영해 cm 단위 선형 깊이로 변환 (투영 깊이의 비선형성 제거)|

## 3. 접평면 기반 후보 계산 (3.3절)

### 식 (3) — 접평면과 굴절 광선의 교차

$$ t_i = \frac{(Q_i - S)\cdot n_i}{d \cdot n_i}, \qquad u^* = \pi\big(S + t_i,d\big) \tag{3} $$

**유도**

1. 배경의 국소 접평면: $Q_i$를 지나고 $n_i$에 수직인 평면 → $(P - Q_i)\cdot n_i = 0$
2. 광선 위의 점 $P = S + t,d$를 대입: $(S + t,d - Q_i)\cdot n_i = 0$
3. $t$에 대해 정리: $t,(d\cdot n_i) = (Q_i - S)\cdot n_i$ → 식 (3)

**해석**

- 분자: 시작점 $S$에서 평면 위 기준점 $Q_i$까지의 변위를 **법선 방향으로 투영한 값**
- 분모: 광선 방향 $d$의 **법선 성분**
- $t_i$는 매 반복마다 **항상 $S$ 기준**으로 계산한다 (이전 교차점에서 이어가지 않음).
- 교차점을 투영한 $u^*$에서 깊이를 다시 읽어 **다음 접평면**을 구성한다 → 이것이 뉴턴 반복.
- 배경 법선 $n_i$는 **접평면**을, 대상 표면 법선은 **굴절 방향 $d$**를 결정한다 (역할 분리).

**반복 종료 조건 (식 3 계산 중 검사)**

|조건|의미|
|---|---|
|$\lvert d\cdot n_i \rvert < 10^{-5}$|광선과 평면이 거의 평행 → 교차 불안정|
|$t_i \le 0$|교차점이 광선 뒤쪽|
|$t_i > 1000$ cm|유효 계산 범위 초과|

## 4. 깊이 불연속에 따른 후보 보정 (3.4절) — 본 논문의 핵심

### 식 (4) — 대각선 이웃 오프셋

$$ \delta = \left(\frac{1}{W},\ \frac{1}{H}\right) \tag{4} $$

- ViewRect에서 **한 픽셀**에 해당하는 정규화 UV 간격.
- 두 성분을 **함께 더해** ($u^* + \delta$) 대각선(+x, +y) 이웃을 선택한다.

### 식 (5) — 깊이 차

$$ g_i = \big|, D(u^* + \delta) - D(u^*) ,\big| \tag{5} $$

- 보정 전 후보 $u^*$와 그 대각선 이웃의 **선형 깊이 차** (cm).
- 이웃 조회 좌표에도 식 (1)을 적용한다.
- **한계(본문 명시)**: 검출이 대각선 **한 방향**뿐이라, 경계의 투영 방향과 표면 기울기에 따라 검출 여부가 달라질 수 있다.

### 식 (6) — 감쇠 계수

$$ \lambda_i = 1 - \frac{1}{2},\mathbf{1}\big[,\text{ON} \ \wedge\ g_i > \tau,\big] \tag{6} $$

- $\mathbf{1}[A]$ : 조건 $A$가 참이면 1, 거짓이면 0인 지시함수.
- 보정 스위치 **ON** 이고 $g_i > \tau = 20,\text{cm}$ 이면 $\lambda_i = 0.5$, 그 외에는 $\lambda_i = 1$.
- **OFF**이면 항상 $\lambda_i = 1$ → 기존 Newton과 동일 (제어 비교용).

|조건|$\lambda_i$|의미|
|---|---|---|
|보정 OFF 또는 $g_i \le \tau$|1|원래 후보 사용|
|보정 ON 그리고 $g_i > \tau$|0.5|이동량 절반|

### 식 (7) — 보정된 다음 후보

$$ \bar{u}_{i+1} = u_i + \lambda_i,(u^* - u_i) \tag{7} $$

- 현재 후보 $u_i$에서 $u^*$로 향하는 **UV 변위에 $\lambda_i$를 곱해** 더한다.
- $\lambda_i = 1$ → $\bar u_{i+1} = u^_$ (원래 후보), $\lambda_i = 0.5$ → $u_i$와 $u^_$의 **중점**.
- 코드(Fig. 3)에서는 `lerp(CandidateUV, NextUV, 0.5f)`에 대응한다.
- 감쇠는 **투영된 화면 좌표(UV)** 에서만 수행한다. $S$, $d$, $t_i$는 그대로 유지하고 UV 이동량만 조절한다.

## 5. 반복 종료 및 수렴 판정 (3.5절)

### 식 (8) — 두 가지 오차

$$ a_i = \lVert u^* - u_i \rVert_2, \qquad b_i = \big|,(S + t_i,d)_z - D(u^*),\big| \tag{8} $$

|오차|의미|단위|
|---|---|---|
|$a_i$|현재 후보와 (보정 전) 새 후보 사이의 **UV 이동 길이**|무차원|
|$b_i$|광선-접평면 교차점의 z 값과, 그 투영 위치의 **배경 깊이** $D(u^*)$의 차이|cm|

- $a_i$ 작음 → 후보가 더 이상 안 움직임 (수렴).
- $b_i$ 작음 → 교차점이 실제 배경 표면 위에 있음 (깊이 일관성).

### 식 (9) — 수렴 판정

$$ \text{converge} \iff (a_i < 0.001)\ \lor\ (b_i < 5,\text{cm}) \tag{9} $$

- 두 오차를 **각각의 임계값**으로 비교하고 **OR**로 결합한다.
- $a_i$는 **보정 전 후보** 기준으로 계산되므로, 성공 플래그는 **보정 전 잔차**에 근거한다. (반환 UV에는 보정이 반영됨)
- 실험의 "내부 수렴 판정 비율" = 이 실행 순서에 따라 성공으로 판정된 픽셀의 비율.

**보충 계산 (본문 3.5절 끝)**: UV 임계값 0.001을 2560×1440에서 픽셀로 환산

$$ 0.001 \times 2560 \approx 2.56\ \text{px (가로 단독)}, \qquad 0.001 \times 1440 \approx 1.44\ \text{px (세로 단독)} $$

대각선 이동은 정규화 UV의 **유클리드 길이**로 평가한다.

**한 번의 반복 순서 (본문)**

1. 배경 위치·법선 복원
2. 접평면 교차 (식 3)
3. 오차 계산 (식 8)
4. 후보 감쇠 (식 4~7)
5. 종료 판정 (식 9)

**종료 조건 요약**: 최대 반복 6회 / 화면 범위 이탈 / 무효 깊이 / 접평면 평행 / 거리 제한. 이 중 **오차 조건을 충족한 종료만 성공**으로 기록.

## 6. 반환 위치와 색 합성 (3.6절)

### 식 (10) — 최종 색 합성

$$ C_{out} = (1 - wM),C_{scene} + wM,C_{refract} \tag{10} $$

- $C_{scene}$: 합성 직전의 장면 색
- $C_{refract}$: HitUV에서 조회한 굴절색
- $M$(대상 가시 마스크)과 $w$(합성 강도)를 각각 0~1로 제한한 뒤 **곱**을 보간 가중치로 사용.

|영역|결과|
|---|---|
|$M = 0$|기존 색 유지|
|$M = 1,\ w = 1$|굴절색으로 완전 대체|
|그 외|두 색의 **선형 보간** (lerp)|

**HitUV 선택 규칙 (수식 아님, 로직)**

|상태|HitUV|
|---|---|
|성공|보정이 반영된 후보|
|실패 + 현재 후보가 화면 안|현재 후보 위치|
|실패 + 현재 후보가 화면 밖|원래 대상 픽셀의 위치|

> 가시한 대상 픽셀의 반환색은 **성공 여부와 무관하게** 합성에 참여한다. $w$는 Fresnel 등 반사·투과 에너지 배분이 아니라 **출력 색을 섞는 강도**로만 정의된다.

## 7. 실험 수치 계산 (4.3절)

수식은 아니지만 본문의 핵심 산술이므로 함께 정리한다.

|시점|OFF|ON|증가 (%p)|
|---|---|---|---|
|정면|86.58%|87.43%|0.85|
|사선|96.49%|96.81%|0.32|

$$ \Delta = \text{ON} - \text{OFF}\ \ (\text{percentage point}), \qquad \text{성공 비율} = \frac{\text{마스크 내 성공 픽셀 수}}{\text{마스크 픽셀 수}} $$

- 마스크 픽셀 수: 정면 264,768 / 사선 278,660
- 증가량은 **반올림 전 값**으로 계산 (표의 반올림 값 차이와 소수 둘째 자리가 다를 수 있음).
- Newton과 보정 OFF는 각 시점에서 최종색·성공 픽셀 수가 일치.

## 9. 수식 관련 점검 메모

1. **기호 충돌**: 식 (1)의 $s$(픽셀 수) vs 식 (2)의 $s$(시작점) — 위 표기 주의 참고.
2. **$u_{i+1}$ vs $\bar u_{i+1}$**: 식 (7)은 $\bar u_{i+1}$로 정의되는데, 이후 "다음 반복의 후보"로 $u_{i+1}$을 쓴다면 $u_{i+1} \leftarrow \bar u_{i+1}$ 관계를 한 줄 명시하면 깔끔하다.
3. **식 (8)의 $b_i$**: $(S + t_i d)_z$는 뷰 공간 z(선형 깊이)와 $D(u^*)$(선형 깊이)를 비교하는 것이므로, 본문처럼 둘 다 선형 깊이(cm)라는 점을 식 근처에 한 번 더 언급하면 좋다.
4. **식 (9)의 OR 결합**: 한쪽 조건만 만족해도 성공이므로, 실험 결론의 "물리적으로 올바른 교차"와 구분된다는 점(본문 서론에서 이미 언급)을 수식 설명에서도 유지.
5. **식 (5)의 $D(\cdot)$**: 이웃 조회가 SceneDepth 기준인지 명확히 하려면 $D(\cdot) = \text{LinearDepth}(\text{SceneDepth}(\cdot))$처럼 정의를 한 번 두는 것도 방법.
6. **식 (3) 부호**: $d\cdot n_i$의 부호는 법선 방향(입사 반대쪽으로 정렬)에 의존한다. 배경 법선 $n_i$의 방향 규칙을 3.3절에 한 줄 추가하면 $t_i>0$ 조건의 의미가 명확해진다.

### List

- push_back, resize, insert, erase

``` cpp

int main()
{
	list<int> li{ 9,7,0,6,1,2 };

	li.resize(10);
	li.push_back(20);
	list<int>::iterator itoffset = next(li.begin(), 4);
	li.insert(itoffset, 68);

	list<int>::iterator it = li.begin();

	for (it ; it != li.end();)
	{
		if (*it % 2 == 0)
		{
			it = li.erase(it);
		}
		else
		{
			it++;
		}
	}
	for ( it = li.begin(); it != li.end(); it++)
	{
		cout << *it << " ";
	}

}
```

iterator erase를 할때 가리키는거 해제되고 다음으로 넘어가지 않도록 유의!!

| 함수/행위      | 시간복잡도        |
| ---------- | ------------ |
| 시작         | O(1)         |
| 중간         | Nod의 위치 O(1) |
| 끝          | O(1)         |
| front      | O(1)         |
| back       | O(1)         |
| push_front | O(1)         |
| push_back  | O(1)         |



### Auto

`auto`는 Type Deduction(추론)으로 값을 복사본으로 간주한다.
Template Type추론과 같은 규칙을 사용하는데, 식의 참조(`&`), `const`, `volattile`을 전부 벗겨내고 타입을 정한다. 참조를 돌려주는 함수/참조 변수로 초기화하더라도 `auto`변수는 새 객체(복사본)이 된다.

```cpp

int x =10;
int& r = x;

auto a = r;   //a는 int 복사본, a를 바꾸더라도 x가 바뀌지 않음
auto& b = r;  //b는 int&, b수정-> x도 수정

const auto cstX = x; // cstX : const int type
```


auto가 자주 쓰이는 형태

| 선언                      | 의미                                                      |
| ----------------------- | ------------------------------------------------------- |
| `auto a = expr;`        | 값 복사 (const, 참조 제거)                                     |
| `auto& a = expr;`       | 참조 (원본 수정 가능). 우변이 const면 `const`가 유지되어 `const T&`로 추론됨 |
| `const auto& a = expr;` | 읽기 전용 참조 (복사 없음, 임시 객체도 받을 수 있음)                        |
| `auto&& a = expr;`      | 포워딩(유니버설) 참조. lvalue면 `T&`, rvalue면 `T&&`               |


**단점**:  
가독성이 좋지 않다 : compile시 type이 정해지는 C++ 장점을 해침

**장점** :  
typing 처리하기 쉽다 : 어떤 타입인지 확실히 알 수있는경우!

##### 일반함수 (runtime 계산)

```cpp
int Factorial(int n)
{
	return n<=1 ? 1 : n * Factorial(n-1);
}
```

실행중 계산되므로 컴파일러가 결과 미리 알 수 없다.
##### constexpr함수 (컴파일 타임 계산 가능)

위와 같이 했던 Factorial 함수를,
Auto 추론을 활용한 컴파일 함수로 만들면

```cpp
constexpr auto Factorial(int n) -> int{ //후행 반환 타입
	return n <= 1 ? 1: n * Factorial(n-1); 
}

int arr[Factorial(5)]   // OK : 컴파일 타임에 120으로 계산 -> 정적배열에 활용가능
constexpr auto x = Factorial(4); //OK : 컴파일 타임 : 24 계산
```


##### Template 특수화 (컴파일 타임 계산 가능)

```cpp
// 일반버전의 template - 특수화 되지 않은 모든 N
template <int N>
struct Factorial{
	static constexpr int value = N * Factorial<N-1> ::value;
};

// 특수 버전의 template : 0일때!
template <>
struct Factorial<0>{
	static constexpr int value = 1;
};

int arr[Factorial<5>::value]; //120
```

`template<>` : 
- template 특수화 <>로 비워둠!

STL에서 제공하는 문법들을 알아보겠다.

List, 
### List

- push_back, resize, insert, erase

``` cpp

int main()
{
	list<int> li{ 9,7,0,6,1,2 };

	li.resize(10);
	li.push_back(20);
	list<int>::iterator itoffset = next(li.begin(), 4);
	li.insert(itoffset, 68);

	list<int>::iterator it = li.begin();

	for (it ; it != li.end();)
	{
		if (*it % 2 == 0)
		{
			it = li.erase(it);
		}
		else
		{
			it++;
		}
	}
	for ( it = li.begin(); it != li.end(); it++)
	{
		cout << *it << " ";
	}

}
```

iterator erase를 할때 가리키는거 해제되고 다음으로 넘어가지 않도록 유의!!

| 함수/행위      | 시간복잡도        |
| ---------- | ------------ |
| 시작         | O(1)         |
| 중간         | Nod의 위치 O(1) |
| 끝          | O(1)         |
| front      | O(1)         |
| back       | O(1)         |
| push_front | O(1)         |
| push_back  | O(1)         |

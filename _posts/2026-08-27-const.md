const는 왼쪽에 있는 항목을 상수화시키는 것이다.  
함수와 변수에서도 당연히 다르다. 

const를 앞에서 붙히냐 뒤에서 붙히냐 했을때 달리지는 것은 알겠는데,  
어떻게 직접 달라지는지 코드로 찍어보기로 했다.

### 변수 선언에서의 const
#### 001 가장 앞에 붙을때
``` cpp
const int* ptr = (int*) 20;
```
가장 앞에 붙었지만 왼쪽항목에 없다면 바로 오른쪽에 있는 것에 붙는 것과 같다

``` cpp
int const* ptr1 = (int*) 20;
```
const가 이렇게 붙는 것 과 같다
왼쪽에있는, `int` 에 const 적용 
- 잠기는 것 : `*ptr` 못 바꿈
- 안 잠기는것 : `ptr`자체( 포인터, 어디가리킬지, 재대입 가능)

#### 002 int* 뒤에 붙을때
``` cpp
int* const ptr2 = (int*) 20;
```
왼쪽에있는, `int*` 에 const 적용 

- 잠기는 것 : `ptr1` 못 바꿈 -> 재대입 불가
- 안 잠기는것 : `*ptr1` 바꿀 수 있음

##### 코드 확인

``` cpp
int main()
{

const int* ptr1 = (int*) 90;
int* const ptr2 = (int*) 40;

ptr1 = (int*) 900; // ...1      Ok  포인터 재대입은 자유
	*ptr1 = 900; // ...2       [Error] 가리키는 값 수정 금지

	ptr2 = (int*) 400; // ...3    [Error] 포인터 재대입 금지
*ptr2 = 400;  // ...4              Ok  포인터 가리키는 값 수정 자유

}
```


#### 정리

| 코드                   | 결과   | 이유                                       |
| -------------------- | ---- | ---------------------------------------- |
| `const int* ptr`     |      |                                          |
| `ptr = (int*) 900;`  | ✅ OK | `a` 자체는 그냥 변수 → 재대입 가능                   |
| `*ptr = 900;`        | ❌ 에러 | `a`는 **"가리키는 값이 const"** → `*a` 수정 불가    |
| `int* const ptr`<br> |      |                                          |
| `ptr2 = (int*) 400;` | ❌ 에러 | `a1` 자체가 const → 재대입 불가                  |
| `*ptr2 = 400;`       | ✅ OK | `a1`은 **"포인터 자체만 const"** → `*a1` 수정은 자유 |

### 02 함수에서의 const  차이

#### 02-1 함수가 Paramter 수정을 못하게하는 `const`

```cpp
class Kick{
...
 Kick& operator=(const T& Other)
 {
	 if( *this == Other ) return *this;
	 Ball* newball = new Ball; //깊은 복사
	 newball = Other._ball;
	 _ball = newball;
	 _power = Other._power;
	 _curve = Other._curve;
	 
	 return *this;
 }
 
 public:
	Ball* _ball = nullptr;
	int _power = 20;
	FVector2D _curve = FVector2D(0.f, 0.f);
 };
```

```cpp
const Kick& other
```
- `Other`를 읽기만 하고 수정하지 않겠다는 의미
- 함수 내부에서 `Other._power`등을 읽는 것 가능
- `Other._power = 30`같은 수정 불가
- 주로 함수가 Paramter를 입력 값으로만 사용할때 사용
> 정확히 `const`가 **Parameter가 가리키는 객체를 수정하지 못하게 하는것**


-> OutParameter로 수정하도록 할때 절대 쓰면 안됨!

#### 02-2 멤버 함수가 객체 수정치 못하게하는 `const`
``` cpp
struct Compare
{
	int threshold = 4; //멤버 변수(상태)
	
	bool operator()(int a) const
	{
		return a > threshold; //threashold는 읽기만함
	}
}
```




```cpp
bool operator()(int a) const
                         // ↑
```
뒤 `const`는 멤버 함수에서 `this`가 **가리키는 객체의 멤버를 수정하지 않겠다**는 의미.

`threshold = 10;` ❌

-> 이는 Functor에서 멤버 변수인 상태를 변경할 일 없을때 활용하기 좋다.


#### 02-3 컴파일 타임 계산을 가능하게 하는 `constexpr`

```cpp
constexpr int getValue()
{
	return 10;
}
```

- `const`와는 다른 개념
- 컴파일 타임에 계산될 수 있는 함수 / 값을 표현
- 조건이 맞으면 compiler가 컴파일 시간에 결과를 계산할 수 있다.

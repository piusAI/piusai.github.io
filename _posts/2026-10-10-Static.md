`static`은 정적 키워드로, 크게 세가지에서 활용한다
- 클래스 멤버에서의 Static : 객체가 아니라 클래스에 종속되는 멤버
- 함수 내부 `static` : 함수가 끝나더라도 살아있다
- 전역 `static` : 한 TU(.cpp 파일)마다 1개씩 존재한다

### 01. Class 멤버에서의 `Static`
- class의 Instance와 종속적않고 클래스 자체에 속하는 멤버
- 객체 없이 `Class명 ::멤버`로 접근
- 주로 싱글톤에서 활용

```cpp
#include <iostream>
using namespace std;

class SingleTone
{
private:
	SingleTone() {
		CallNum++;
		cout << "Call Num : " << CallNum << endl;
	}
	~SingleTone() {}
	SingleTone(const SingleTone&) = delete;
	SingleTone& operator=(const SingleTone&) = delete;

public:
	static SingleTone* GetInstance() {
		if (g_instance == nullptr)
			g_instance = new SingleTone;
		return g_instance;
	}

public:
	static int CallNum;
	static SingleTone* g_instance;
};

// static 멤버는 클래스 밖에서 정의
int SingleTone::CallNum = 0;    
SingleTone* SingleTone::g_instance = nullptr;

int main()
{
	cout << SingleTone::CallNum << endl;   // 0
	SingleTone::GetInstance();             // 생성 → Call Num : 1
	SingleTone::GetInstance();             // 이미 있음 → 출력 없음
	cout << SingleTone::GetInstance()->CallNum << endl;  // 1
}
```


### 02. function 내부에서의 `static`
- 생명 주기가 전역변수와 같다. 함수가 끝나도 값이 유지!
- 유효 범위(Scope)는 역시 선언된 함수 안. 함수 밖에서 직접 접근 불가.
- 초기화는 딱 한번, 함수가 처음 호출될때!!

```cpp
void GetCallThis(){

	static int counter = 0; //딱 한번만 초기화
    return counter ++; // 함수 끝나도 값 유지!
}

GetCallThis(); // 0 return, counter == 1
GetCallThis(); // 1 return, counter == 2
GetCallThis(); // 1 return, counter == 3
```


### 03. 전역 변수 / 함수에서의 `static`
- 내부 연결성을 부여하는 키워드 (GEA-3.3.4 참고) 
- Linker가 TU마다의 별개의 변수로 취급한다.

``` cpp
//A.h
static int PlayerNum=0;
void addPlayer();
int GetPlayerNum();

//A.cpp
#include "A.h"
void addPlayer() { PlayerNum++; }
int GetPlayerNum(){ return PlayerNum; }

//main.h
#include "A.h"
int main()
{
addPlayer();
addPlayer();

cout<< "main.cpp - Player : "<< PlayerNum <<endl;
cout<< "A.cpp - Player : " <<GetPlayerNum()<<endl;
}

// > main.cpp - Player : 0
//   A.cpp - Player : 2


```

- 헤더에 `static`변수를 두면 `#include`한 TU마다 복사본이 생기므로, 위처럼 값이 따로 논다.


### Static 세가지 용도 비교

| |클래스 멤버 static|함수 내부 static|전역/파일 static|
|---|---|---|---|
|**선언 위치**|클래스 안|함수 안|함수/클래스 밖 (파일 스코프)|
|**소속**|클래스 자체 (인스턴스 무관)|해당 함수|해당 TU(번역 단위)|
|**접근 방법**|`클래스명::멤버`|선언된 함수 안에서만|해당 TU 안에서 어디서나|
|**생명주기**|프로그램 전체|프로그램 전체|프로그램 전체|
|**초기화 시점**|프로그램 시작 시 (클래스 밖에서 정의)|함수 첫 호출 시 1회|프로그램 시작 시|
|**연결성**|외부 연결성 (클래스 멤버로서 공유)|연결성 없음 (지역 범위)|**내부 연결성** (TU마다 별개)|
|**복사본 수**|프로그램 전체에 1개|1개|`#include`한 TU마다 1개씩|
|**스레드 안전**|보장 없음 (직접 보호 필요)|초기화만 안전 (C++11~)|보장 없음|
|**주 용도**|싱글톤, 인스턴스 간 공유 데이터|호출 횟수 기억, 지연 초기화, Meyers 싱글톤|파일 내부 전용 변수/함수, 이름 충돌 방지|
